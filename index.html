Переписка учебного заведения, которую никто, кроме вас, не прочтёт

Secure Messenger — мессенджер для колледжа: чаты, группы, сообщества, звонки, учебные задания и расписание. Сообщения и файлы шифруются на вашем устройстве, сервер хранит только шифротекст.

Скачать для Windows Все установщики (macOS, Linux)

Тест закрытый: войти можно только по личному ключу-приглашению. Ключ выдаёт администратор.

01/ как начать

Три шага

  1. Установите приложение

    Скачайте Secure.Messenger_0.8.1_x64-setup.exe со страницы релиза и запустите. Установщик пока без цифровой подписи, поэтому Windows может показать окно SmartScreen: нажмите «Подробнее» → «Выполнить в любом случае».

  2. Откройте вкладку «Регистрация по ключу»

    Адрес сервера уже встроен в приложение, ничего настраивать не нужно. Введите ключ вида SM-XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX, придумайте имя пользователя (латиница, цифры, _ . -) и пароль от 8 символов.

  3. Войдите и пользуйтесь

    Ключи шифрования создаются на вашем устройстве. Сохраните код восстановления, который приложение предложит записать: без него переписку на новом устройстве не восстановить.

02/ шифрование

Сквозное

X3DH и Double Ratchet для личных чатов, sender keys для групп. Сервер не может прочитать сообщения и файлы.

03/ доступ

Только по ключу

Регистрация закрыта. Ключ одноразовый или на группу, у него есть срок действия, и его можно отозвать.

04/ звонки

Голос и видео

Личные и групповые звонки с шифрованием кадров. Работают из любой сети: дома, в колледже, по мобильному интернету.

05/ материалы

Всё под рукой

Фото, файлы, ссылки и голосовые из каждого чата собраны в «Общих материалах».

06/ важно

Это Alpha-версия

  • Возможны ошибки. Если что-то не работает, напишите администратору, который выдал вам ключ.
  • Не передавайте свой ключ другим: он привязан к вашему приглашению, и администратор видит, кто по нему зарегистрировался.
  • Обновления выходят часто. Если приложение попросит обновиться, скачайте новый установщик с этой страницы.
